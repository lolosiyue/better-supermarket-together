# 記憶與行為設定（1.4.7）

在 F7 對 DeepSeek 娘說明需要記住的長期偏好，例如：

- 「記住，不要偷吃白飯。」
- 「記住，少做小動作。」
- 「記住，不要整理裙擺，但可以伸懶腰和左右看。」
- 「記住，閒時可以主動幫忙補貨。」

DeepSeek 使用既有 remember 工具，儲存一項一行的明確行為偏好；工具成功及 F7 生效摘要可確認，不只依她的對話承諾判斷。更新同一項會取代舊值。forget_memory 依記憶編號刪除該設定及舊的衝突版本，恢復設定檔預設。清除所有記憶亦恢復預設。設定檔關閉功能時，記憶不能重新開啟它。

支援格式：`行為偏好｜主動幫忙：開`；同樣可使用「偷吃白飯」「伸懶腰」「左右看」「整理裙擺」，值為「開／關」。「小動作頻率」值為「一般／較少／關」。較少為每 3–6 分鐘一次隨機機會；一般為 1–2 分鐘，皆保留 65% 機率與閒置條件。

既有記憶中完全符合「不要偷吃」「不要偷吃白飯」「少做小動作」「不要做小動作」「不要主動幫忙」「主動幫忙補貨」「優先補貨」「不要伸懶腰」「不要左右看」「不要整理裙擺」等明確短句也會生效。自由敘述、條件句、姓名與一般喜好不會靠關鍵字猜測成行為設定；可再請她把該偏好記為支援的格式。

主動幫忙只影響閒時補貨，不搶走原職責，不覆蓋安全交接。沒有新增找玩家交代。偏好保留於各商店既有記憶 JSON，不修改存檔或使用者的實際舊記憶檔。
