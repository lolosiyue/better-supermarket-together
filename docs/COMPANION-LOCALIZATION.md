工作計畫、步驟、補貨進度、選取貨架、派工／路徑錯誤、自主狀態與 cache 用量標籤，已統一使用 `ModText` 翻譯表。F10 的介面語言設定亦套用到 F7；切換語言會重新顯示目前狀態，無需重新派工。

計畫控制器回傳「訊息鍵＋參數」。成功／失敗由 `CompanionPlanPhase` 判斷；已移除顯示字串中的英文前綴判斷和整段 `Replace` 翻譯。商品 ID、貨架 ID、商品名稱、員工名字和玩家偏好皆以參數帶入。

翻譯採用隨插件打包的固定對照，不會為了顯示狀態而呼叫 DeepSeek。修改翻譯表來源後需重新測試及建置。若提供 TSV 匯出，它是便於審閱的對照快照，來源仍為上述 catalog。

## 執行紀錄與 API

新產生的執行紀錄會保存 `Notice` 的鍵及參數，載入後可顯示中文或英文。同一紀錄的 API 文字固定保存為英文，顯示語言切換不會重寫已傳送的對話前綴。

查閱商店的工具仍向模型回傳完整 JSON；聊天面板會顯示翻譯後的查閱摘要。自主回覆的「自主評估」標記獨立保存，模型實際生成的回答原文不參與介面翻譯。

既有記憶檔版本保持 1，新增欄位為可選。舊紀錄沒有訊息鍵，會顯示原文；無法識別或參數不合法的 notice 亦會回退到原文。玩家及模型對話、偏好內容不作關鍵字替換。記憶仍保留最近 40 則，原有寫入及備份機制沿用。
