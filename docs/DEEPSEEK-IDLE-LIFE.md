# DeepSeek 娘日常行為（1.4.6）

預設開啟本機主動補貨與閒時小動作，不需要 API。原有 API 自主模式、玩家計畫、聊天請求及白飯彩蛋優先，避免同時控制。

主動補貨：持續確認閒置至少 15 秒，尋找 12 米內可行走到達、有未被占用且可到達的倉庫庫存的一格普通貨架。確認有實際補入後停止擴展工作，安全處理餘貨再恢復原職；不保證一次補滿整格。庫存耗盡、別人接手或 90 秒仍未有結果便退出，正在持貨則等安全交接，不強制丟貨。嘗試至少相隔 180 秒。

休息員工可以幫忙；沒有箱子要收的倉管、沒有維修或紙箱包工作的技工、沒有訂單的打包員，以及未分配收銀台且沒有可接收銀台的收銀員可參與。補貨員保留原生補貨流程；保安和生產員本版不借調。玩家手動改職責優先，不恢復過時職責。

閒時隨機伸懶腰、左右看、雙手整理裙擺。動作約 3–5 秒，每 60–120 秒有一次 65% 隨機機會；工作、移動、拿物品或玩家介入會約 0.3 秒淡出。動作不改職責、不停用原生導航。裙擺動作是雙手拂整姿勢，不是手掌與布料抓握模擬。

沒有走近玩家交代，僅沿用 F7 執行結果。動畫僅房主本機顯示；實際補貨走原生伺服器流程。

設定：BepInEx 設定的 Companion.ProactiveHelp、Companion.IdleGestures 可各自關閉。原有 API Autonomy 開啟時，本機日常行為讓出控制權。

驗證：Release 編譯通過，293 項同伴檢查通過（新增 18 項閒置判斷、冷卻與 API schema 隔離測試）。尚未進遊戲驗證動畫自然度、穿模或補貨端到端行為。
