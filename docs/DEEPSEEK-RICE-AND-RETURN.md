# 臨時派工復職與白飯彩蛋（1.4.3）

## 預設做完回原職

「叫 3 號去補貨」現在預設完成一輪有進度的原生工作，放妥手上物品後回到接令前職責。生產的一輪沿用遊戲員工原料交付進度，不代表完成整批成品。可以說「讓 3 號支援收銀五分鐘」，之後同樣復職；「永久調 3 號去收銀」才會保持新職務。沒有進度的一輪任務十五分鐘後安排安全返回；不會強行丟下搬運物品。

同伴本人的有限計畫也恢復原職。連續臨時派工會保留最初職責；玩家手動調職優先，取消舊的自動復職。停止／取消臨時計畫會等候安全復職。原職追蹤限本次房間會話，離開前請先等候復職；不跨讀檔恢復。

## 偷吃大白飯

預設開啟。第一次及後續成功偷吃之間為隨機 20–40 分鐘的非暫停遊戲時間，每個遊戲日最多一次。不使用 DeepSeek API 作隨機判斷。

只在她職責為休息、已停下、空手、沒有工作計畫／自主模式／聊天請求且沒有罷工時觸發。候選商品是實際遊戲資產確認的三款：普通米（ID 3）、Basmati 米（33）、長粒米（34）。同時核對 prefab 名稱，不會把米帽或雞肉飯誤算進去。

從有貨且能走到的款式等機率隨機選一款，再走去該款最近的可達貨架。到達後透過遊戲原生 NPC 取貨方法扣一個零售商品單位，核對只少一份。無貨、路徑失效、外觀未載入或動作道具建立失敗時不扣貨；沒有金錢收入。這是白飯趣味演出，遊戲米商品是按包／單位扣減，不另模擬煮飯製程。

動作約八秒：左手捧碗、右手舀飯三次、輕微低頭，結束後放下手並繼續原本休息流程。飯碗依款式變色。碗、飯和木匙在程式內生成，不另下載模型。動作與外觀只在房主本機顯示，庫存更新使用遊戲原生同步路徑。

開始工作、聊天、手動改職務、停用插件、重綁或離開時會中止動作並清除道具；已吃掉的一份不會補回，也不會重扣。F7 聊天會留下簡短的商品與庫存 -1 紀錄。可在設定檔 `[Companion]` 將 `RiceEasterEgg = false` 關閉。

## 驗證

Release 編譯成功，275 項自動檢查通過。使用實際遊戲資產確認米商品 ID／prefab 及原生庫存扣減方法；自動檢查使用假的庫存與員工狀態，沒有更改遊戲存檔、庫存或呼叫真實 API。

遊戲內路徑、扣貨同步、捧碗／舀飯的手部觀感、模型穿模及效能仍待實機驗收。這裡是程式式骨架動作，不是已完成視覺驗收的動畫片段。

## 安裝

關閉遊戲，備份原 BetterSupermarketTogether.dll，將安裝包的 BepInEx 資料夾合併到遊戲目錄。保留原有設定、API 金鑰和記憶。本次未自動安裝。回退時恢復備份 DLL。
