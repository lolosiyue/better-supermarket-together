# 跟隨助理（1.4.9）

F7 可用語句：

- 「跟著我，當我的助理。」進入持續跟隨模式，記住原本職責。
- 指著一般商品貨架再按 F7：「這格幫我補一下。」助手親自補貨。
- 同樣指著貨架：「叫個空閒員工來補這裡。」助手留在你身邊，派空手、正在休息且沒有臨時計畫的同事補指定貨架。同事完成後回原職；找不到合適同事就回報未派出，不假裝成功。
- 「帶我去放白飯的貨架。」先解析商品與貨架；有多個位置就請你指定。助手行走帶路，距離你太遠便等待，最多三分鐘；到達或失敗後繼續跟隨。
- 「這格為甚麼空著？」讀取目前數量、倉庫庫存、助手能否到達與其他員工是否已接手。未觀測到的原因不當作事實。
- 「回原本工作。」退出助理模式，安全處理手上貨物後回原職。

個人差事結束後回到跟隨，不恢復原職；同事差事則仍恢復同事自己的職責。持續助手模式會讓本機主動幫忙、白飯彩蛋及閒置行為讓出控制。手動改職責、停用插件、解除綁定與換商店視為取消控制，不跨商店延續助理模式。

目標來源是開啟 F7 時的準星；打開後若要換貨架，先關閉面板再指向新目標重新開啟。既有選取貨架按鈕仍可使用。也能提供商品名稱、商品 ID 或查閱結果的 shelf_id。沒有目標或有歧義時不派工。

目前範圍是普通零售貨架與倉庫箱子，不包含生產貨架、購物、修改價格、轉移物品到玩家手上。跟隨／帶路不會瞬移。無法到達時保留助理模式並間隔重試跟隨；回原職指令仍有效。
